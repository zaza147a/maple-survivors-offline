# 遊戲規格：POE 式永久養成 × Roguelite
版本 0.0.2（2026-11-25）

## 正式方向
2D 俯視角單機動作刷寶 RPG，不再以固定時間存活為主要目標。局外角色、裝備、天賦、技能連結永久保留；局內隨機房間、祝福與戰鬥構築於冒險結束後重置。所有第三方素材須具備使用權；原型僅使用幾何圖形，不使用第三方遊戲原始碼或素材。

## 本版原型
- 據點：四職業選擇、三類永久天賦（每類最多五點）、單一護符欄、經驗與金幣。
- 地城：五層，前四層隨機二選一路線，第五層首領。普通、精英、休息、寶箱、首領房間。
- 戰鬥：方向鍵／點擊移動、自動攻擊、追蹤敵人、接觸傷害；四職業有不同基礎射程、攻速、傷害、生命。尚無獨立技能動畫或手動技能。
- 每非首領房間完成後三選一祝福：攻擊、生命、攻速、多目標、吸血。
- 首領通關才帶回經驗、金幣、護符；死亡或放棄丟失本局戰利品，永久存檔保留。每100經驗一點天賦。這是原型暫定規則，之後評估撤離／部分保留。
- 本地存檔：v2，單一共用角色養成資料；切職業共享養成僅為測試便利，正式版預計多角色獨立養成。局內不續存。

## 後續正式規格（未實作）
第一完整版本目標：四職業、8昇華、100天賦節點、16技能、20輔助寶石、50祝福、40裝備詞綴、3地城主題、6首領、Lv60、T1–T5。長期目標：12職、36昇華、600+天賦、100+技能及輔助寶石、300+祝福、200+詞綴、15+地城主題、30+首領、Lv100、T1–T16。上述為設計目標，不是已完成內容。
裝備：五品質、前後綴各三、T1–T7、卷軸強化、製作貨幣、特殊機制裝備。共用天賦樹與職業昇華；技能本身配置輔助寶石，不綁裝備。地圖道具可洗詞綴；獨立後期地圖天賦。局外/局內戰力目標60/40，須用模擬驗證，非固定公式。
